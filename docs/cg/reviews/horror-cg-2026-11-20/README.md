# Horreur — livraison par univers

Cette vague livre **66 décors CG03** répartis sur **17 univers d’horreur**. **3 variantes de Jonas Mire** portent le Testament des noyés à 45 CG sur 45. La galerie contient 70 décors pour les 70 fiches du roster dans les univers sélectionnés, dont quatre décors Resident Evil déjà livrés.

Les décors reprennent les périodes, les fonctions des lieux et les repères d’ambiance des fiches du jeu. Leur agencement reste propre à Multiverse Breach. Les variantes de Jonas Mire s’appuient sur le portrait V2 et les thèmes prévus dans sa fiche de production.
