# Alien, Predator et Infernum

**51 nouveaux décors CG03** portent la famille Alien et Predator à **66/66** fiches équipées dans **16 univers**. **10 scènes de Morcant l’Enchaîné** portent sa série à **15/15** dans *Infernum: Nine Pits*.

Les décors sont des lieux originaux de Multiverse Breach, fondés sur les périodes et les environnements du roster. Les fiches héritées gardent leurs identifiants et les décors suivent leur incarnation respective.
