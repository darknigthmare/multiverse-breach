# Première passe gelée des renforts W10

Les 16 tests Node et les 16 parcours réels GameCanvas ont terminé au code 0. Les deux camps ont chacun rendu les 128 cellules natives ; 256 miroirs de pixels ont été vérifiés. Les seize effets se déclenchent une fois à tick99, avec douze impacts offensifs et quatre soutiens alliés sans dégât ni soin. Aucune erreur de page.

Cette preuve conserve la première version effectivement exécutée. Root a ensuite rouvert une fenêtre de corrections, dont la sélection du soutien auteur de Mei Zhen ; une nouvelle passe sera nécessaire après son signal de gel final. Les sources partagées n’avaient pas été empreintées à l’exécution et aucune empreinte actuelle n’est présentée comme celle de ce premier run.

Le dossier `summon-wave10-first-freeze/` conserve le résultat, le harness et les seize captures, avec les deux montages inspectés. Les erreurs de fixture Node précédentes restent archivées séparément. Les vingt PNG, deux registres, les ancres et les capacités du lot B correspondent toujours aux empreintes de livraison. Aucune source production n’a été modifiée par cette vérification.

Le contrôle utilise de vrais moteurs et composants, avec des PV et jauges de formation pour isoler l’action. Il ne certifie ni l’ensemble des animations originales image par image ni la distribution HTTP du build final.
