# Featured Item Reference Audit

This file records the canonical physical props used for generated pickup icons.
Legacy item IDs stay unchanged where saves already depend on them.

## Tomba

- Grandfather's Golden Bracelet: the heirloom stolen by the Koma Pigs.
- Blue Evil Pig Bag: the bag given by the Dwarf Elder.
- Charity Wings: the fast-return item from the original game.
- Black Evil Pig Bag: the eighth bag that reveals the Real Evil Pig.
- Tomba's Spiked Ball: his chained signature weapon.
- 100-Year-Old Man's Key: the large golden quest key.
