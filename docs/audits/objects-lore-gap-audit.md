# Audit des ecarts lore - objets

Date de l'audit : 2026-07-17

## Perimetre et methode

Cet audit couvre les objets ramassables, les equipements et les items d'evenement exposes par les catalogues runtime :

- `EQUIP_ITEMS_DB` : 876 equipements, repartis sur 292 univers apres exclusions ;
- `EXPANDED_GEAR` : 765 equipements apres exclusions ;
- `EXPANDED_EVENT_ITEMS` : 255 items d'evenement apres exclusions ;
- `BATTLE_ITEM_CATALOG` : 1 460 entrees, reparties sur 292 univers apres exclusions.

Ces nombres se recouvrent : ils decrivent plusieurs vues runtime des memes donnees et ne doivent pas etre additionnes.

Exclusions demandees, non auditees dans les tableaux : Tomba, Woodruff, Hellraiser, A Nightmare on Elm Street, The Ring et The Grudge.

Constats automatiques :

- 115 univers utilisent encore exactement le quartet `Signature Relic`, `Field Plate`, `Nexus Core`, `Breach Signal`, soit 460 enregistrements generiques ;
- 278 univers utilisent encore les 834 IDs techniques `*_field_relic`, `*_survival_cache`, `*_tempo_core` dans `BATTLE_ITEM_CATALOG`, meme lorsque le nom affiche est remplace par un objet plus precis ;
- 43 equipements de 39 univers contiennent encore `Core`, `Relic`, `Cache`, `Shard`, `Fragment`, `Sigil` ou `Nexus` hors quartet exact ; certains sont canoniques et doivent etre conserves, les autres sont signales ci-dessous ;
- 140 items d'evenement personnalises ont ete controles. Une action, une attaque, un statut, un montage, une transformation ou une notion abstraite n'est pas un objet ramassable : le tableau propose alors un accessoire physique canonique qui porte le meme effet.

Ordre des references : page officielle ou manuel officiel, musee/archives d'accessoires, puis encyclopedie specialisee lorsque l'objet n'est pas documente officiellement. Une URL sert a verifier silhouette, materiaux et contexte ; elle ne doit pas etre copiee pixel pour pixel.

## Legende

- **P0** : fallback generique exact, source impossible a identifier, ou absence totale d'objet canonique exploitable ;
- **P1** : objet abstrait, fragment invente, action transformee a tort en item, ou silhouette non canonique ;
- **P2** : objet physique deja canonique mais nom/ID trop abstrait, ou reference visuelle a verrouiller avant production.

Dans les tableaux, `FG4` signifie **FALLBACK GENERIQUE exact** : `Signature Relic` + `Field Plate` + `Nexus Core` + `Breach Signal`. La notation `stem_{sigil,armor,core}` developpe trois IDs reels distincts. Elle ne masque donc aucun enregistrement.

## Prompt standard

`P512(objet)` signifie :

> Icone pixel art originale 512x512 RGBA, un seul objet physique canonique [objet], vue 3/4 legerement plongeante, objet entier centre, silhouette, proportions, materiaux et palette fideles a la reference visuelle citee sans recopier une image officielle, contour pixel net, details lisibles a petite taille, ombre de contact discrete, fond transparent, aucun personnage, main, texte, logo, cadre ni watermark.

`P512x4` signifie quatre generations separees avec `P512`, une image par objet cite et jamais quatre objets dans la meme icone.

## Synthese de correction

1. Remplacer en premier les 460 enregistrements `FG4`. Ils sont a la fois generiques dans le nom, dans l'ID et dans la description.
2. Migrer ensuite les 834 IDs runtime `field_relic`, `survival_cache`, `tempo_core` vers des IDs d'objets concrets. Une table de migration doit conserver la compatibilite des sauvegardes.
3. Corriger les entrees P1 `Core/Shard/Fragment` : elles produisent aujourd'hui des cristaux, noyaux ou morceaux interchangeables alors que la franchise fournit un accessoire complet.
4. Pour les items d'evenement, conserver l'effet gameplay mais remplacer le support visuel par l'objet physique propose. Le nom peut devenir `Objet - effet`, par exemple `Ghost Trap - Cross the Streams`.
5. Ne rien generer pour `Spoof Movie`, `ASMRZ` et `Despicer` avant clarification de la source exacte. Une reference inventee serait plus grave qu'un fallback visible.
6. Produire chaque icone separement en 512x512 RGBA, puis verifier a 64x64 et 32x32 : silhouette lisible, alpha propre, aucun texte parasite et aucun morceau coupe.
