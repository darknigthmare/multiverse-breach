## Perimetre

- Fichier runtime inspecte: `src/game/enemies.js`.
- Extensions comparees: `src/game/expandedUniverses.js` et `src/game/loreAccuratePacks.js`.
- Etat image compare: `public/sprites/generated/sprite-manifest.json`, `public/sprites/generated/openai-sprite-prompts.jsonl` et presence des PNG declares.
- Filtre strict: `kind: enemy`. Aucun tableau boss ou world boss n est traite.
- Priorite de cette version: les 345 fallbacks `Rift Drone`, `Breach Stalker` et `Anomaly Pack`.
- Regle de curation: un remplacement n est `CONFIRME` que si une page directe montre ou decrit cet ennemi precis. Sinon le slot reste `A_VERIFIER` et son prompt est bloque.
- Les groupes musicaux, comedies ou oeuvres sans bestiaire stable ne recoivent plus de figurants de clip inventes.
- ASCII uniquement pour eviter les problemes d encodage.
