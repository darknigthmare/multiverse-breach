## Convention des ID

Les objets boss n'ont pas d'ID source persistant. Le moteur et le manifeste le calculent avec :

```text
id = slugify("<univers>-<nom du boss>")
```

Dans le tableau des fallbacks :

- `EG` signifie l'entree actuelle `"<Univers> Elite Guardian"` et son ID `slugify("<Univers>-<Univers> Elite Guardian")`.
- `CA` signifie l'entree actuelle `"<Univers> Crisis Avatar"` et son ID `slugify("<Univers>-<Univers> Crisis Avatar")`.

Chaque ligne A/B ci-dessous represente donc deux entrees distinctes et fournit pour chacune la cible, le gameplay, le verrou visuel, la reference et le prompt.

## Gabarit sprite obligatoire

`P4X4` designe le prefixe complet suivant :

```text
Use case: stylized-concept. Asset type: game sprite sheet for a 2D canvas battle game.
Create one original, highly detailed dark-fantasy pixel-art animation sheet, 1024x1024,
exactly 4 columns x 4 rows, sixteen equal 256x256 cells. One subject only, full body,
three-quarter side battle angle facing right, centered with identical scale and anatomy
in every cell. Row 1: idle breathing. Row 2: walk/run cycle. Row 3: canonical signature
attack with the stated weapon or power. Row 4: hit/recoil cycle. Preserve the source
silhouette, clothing, anatomy, equipment and palette; do not invent cross-franchise gear.
Perfectly flat solid #00ff00 chroma background, no floor, no cast shadow, no text, no
labels, no border, no watermark, no cropped limbs, no duplicate subject.
```

Dans chaque entree, `P4X4 + "..."` est un prompt complet : il faut concatener le bloc ci-dessus avec le verrou specifique indique.

## Priorites

- **P0** : remplacer ou retirer avant toute generation. Le nom actuel casse le lore ou creerait un faux asset.
- **P1** : corriger attribution, doublon, forme ou phase avant generation.
- **P2** : boss canonique correctement attribue, sprite seulement manquant ou libelle a normaliser.
- **N/A** : ne pas generer de sprite de boss; convertir en hazard, objectif, dialogue ou challenge.

## F. Regles d'integration

- Ajouter un champ de provenance par entree : `canonSourceUrl`, `continuity`, `year`, `phaseOf`, `isEncounter` et `isWorldBoss: false`.
- Ne jamais faire remonter un boss d'un film derive vers l'univers racine si l'univers du film existe deja.
- Utiliser `phaseOf` pour Spark, Gravemind, Saren, REX, Justice, Voldemort, Feral Predator et les transformations de kaiju.
- Utiliser `isEncounter` pour les challenges comiques, avatars de clips et confrontations narratives.
- Utiliser `bosses: []` lorsqu'une oeuvre ne possede pas de boss combat canonique; le fallback automatique actuel doit alors etre desactive.
- La validation finale doit verifier : nom canonique, univers/annee, absence de doublon semantique, image 1024x1024, grille 4x4, seize cellules coherentes, aucune frame coupee et aucun world boss injecte dans la liste locale.
