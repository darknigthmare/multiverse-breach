# Naruto - generated complete stage pack

Date: 2026-07-26

## Scope

- `combat.webp`: Forest of Death combat lane
- `melee.webp`: Valley of the End brawler backdrop
- `melee-backdrop.webp`: Valley of the End parallax backdrop
- `melee-platforms.webp`: six isolated lore-material platforms
- `rpg.webp`: Chunin Exam preliminary arena, side-view
- `tactics.webp`: Konoha rooftops, high three-quarter view
- `tactics-tiles.webp`: eight isolated tactical ground tiles

## Reference

- https://naruto-official.com/en/anime/naruto1

The artwork is original fan-made pixel art generated with the built-in OpenAI
image tool. The reference was used for visual and chronology fidelity; no
official bitmap asset was copied into the project.

## Runtime contract

| Asset family | Size | Mode |
| --- | ---: | --- |
| Combat / Melee / RPG | 1672 x 941 | RGB |
| Tactics | 1448 x 1086 | RGB |
| Melee platforms / Tactics tiles | 1254 x 1254 | RGBA |

Both transparent atlases have alpha range `0..255`, no visible magenta key
pixels, and zero hidden RGB in fully transparent pixels.
