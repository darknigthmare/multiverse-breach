# Fichiers retrouvés à provenance incomplète

4 PNG natifs sont conservés ici, sans retouche, afin de ne pas perdre le travail retrouvé. Ils sont exclus du catalogue, du vestiaire et du total livré.

Les identités proposées reposent sur les tâches interrompues, les horodatages et une comparaison visuelle des références. Les prompts exacts et réponses de génération manquent : le champ `prompt` reste donc `null`. Les images utilisées pour la comparaison actuelle ne sont pas présentées comme des entrées de génération prouvées.

Voir [index.json](index.json) pour les empreintes, dimensions, attributions candidates et limites.
