# Ligne de vue des boss en Tactics

Le volume d’interception suit les cases du combattant, y compris le recalage au bord du plateau. Une attaque qui s’arrête au contact d’un corps ne traverse plus la deuxième rangée d’un boss 2×2. Le joueur peut viser une case secondaire du boss lui-même. Les tirs perforants conservent leur passage.

Au Carrefour de la Cité Libre, le Last Engineer occupe les cases (2,6), (3,6), (2,7) et (3,7). Aelwen essaie de tirer de (0,7) vers (6,7) avec un profil de vérification qui bloque sur les unités. La commande est refusée et la cible derrière le boss garde ses PV. Un tir sur (2,7) atteint le boss. Le second test vérifie le recalage du volume le long du bord est.

Les deux régressions échouent avant le correctif. Les 51 tests ciblés passent dans un miroir temporaire du code qui réutilise les médias et les dépendances du dépôt. L’outil de lint signale un repli de spread déjà présent dans la normalisation du terrain. [Reçu](verification.json)
