# Navigation dans le registre des packs DLC

Dans **Système → Packs DLC**, Page suivante et Page précédente placent le focus sur la première fiche nouvellement visible et la ramènent dans la zone de défilement. La recherche et le filtre restent actifs. Entrée ouvre cette fiche, la remise à zéro rend le focus à la recherche et Échap revient au bouton des archives.

Les 21 tests Node et les 12 scénarios Chromium passent. La pagination a été vérifiée dans six contextes de registre, en français et en anglais, sur trois tailles d’écran et avec le texte agrandi à 150 %. Les parcours relevés ne déclenchent aucune écriture de stockage, erreur JavaScript ou réponse HTTP en échec.
