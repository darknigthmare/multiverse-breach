# Les trois chargements de Kelly

Les 48 cellules des trois planches DLC ont été inspectées. Le Kelly de base montre un dôme à antenne et plusieurs hologrammes. Les variantes Electro-Beam et lance-flammes dessinent des machines blindées, avec une lampe dorsale sur la variante feu. Plusieurs cellules comportent aussi des fragments clairs opaques. Les deux références de 1997 conservées par le projet montrent un corps d’araignée organique et cybernétique. La source décrit les armes offensives montées sur les pattes avant. [Audit de l’identité](../../../audits/fidelity-spider-kelly-source-review-2026-10-18.json) · [Mesures des planches](verification.json)

Les trois anciennes planches restent dans les archives du DLC. Les sélecteurs de jeu les écartent pour les incarnations visées, y compris avec une identité technique J2 ou CPU. Un repère signale l’art en attente en RPG, Mêlée et Tactics. Le Kart conserve son véhicule sans image de pilote et Extinction utilise son schéma de secours. Les commandes conservent la lame de base, le rayon électrique et le jet de flamme. Les trois P0 artistiques restent ouverts. Le DLC contient les anciens robots et trois véhicules de Kart. Les références existantes permettent d’écarter les robots, mais aucune planche de combat disponible ne permet de vérifier les proportions du corps, le montage exact des trois accessoires et les poses du modèle PlayStation à l’échelle du jeu.
