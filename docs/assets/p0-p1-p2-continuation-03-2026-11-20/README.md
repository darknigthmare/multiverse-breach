Les contrôles ciblés comprennent aussi 34 tests DLC, 25 pour les présentations de duel et 14 pour le briefing. Les tests se recoupent. Les compilations couvrent l’édition complète, le jeu de base et une édition avec les trois packs originaux de Thalassa, Méridien et Viridienne.
