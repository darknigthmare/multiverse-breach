# Renforts W11 — preuve finale

Les 16 tests Node et les 16 parcours réels GameCanvas terminent au code 0 après le dernier gel de production, incluant le correctif des anciens projectiles des soutiens ordinaires. Les sept nouveaux renforts ont 112 poses natives distinctes, rendues dans chacun des deux camps ; les 224 contrôles de miroir portent sur ces mêmes poses. Les 14 scènes offensives appliquent chacune un seul impact de PV. Les deux scènes Protego d’Hermione protègent leurs deux véritables alliés, sans soin ni dégât adverse et sans nouveau PNG compté.

Les parcours utilisent le bouton GameCanvas, l’annulation sans coût, U/PavNum5, la confirmation des cibles, la vraie propriété sessionPaused, la reprise puis la commande désactivée après utilisation. La progression appelle les update/draw de production. Chaque scène consomme 100 ATB et 100 de charge une seule fois. Les tests Node couvrent aussi interruption, disparition du lanceur, fin de combat, dispose, refus de contact absorbé par un bouclier et coordonnées d’impact conservées après déplacement/KO. Ils vérifient les 40 partenaires : 28 bindings natifs, 12 replis réels ; les 23 précédents atlas natifs, leurs métadonnées et les 28 anciennes feuilles à quatre poses restent identiques aux références W11.

Les seize captures finales ont été inspectées dans les deux montages `summon-wave11-final-captures-*`. Spike approche physiquement, Lancelot utilise son épée ; les cinq tireurs portent leur arme et ne créent pas de nouveau corps procédural. Hermione utilise ses anciennes poses de course pour l’arrivée et le retour, puis la rangée calme 0 pour Protego, sans rayon offensif. Ce repli n’est ni un atlas16 ni une nouvelle animation dédiée. Aucun défaut matériel de rendu et aucune erreur de page n’ont été constatés dans ces captures.

Les 312 fichiers suivis gardent leurs empreintes avant et après le run final : imports relatifs JS/JSX/JSON accessibles depuis GameCanvas, sept PNG natifs de renforts et vingt PNG du lot B. Les vingt PNG B, ses deux registres, ses ancres et son module de capacités concordent également avec leur livraison figée. Les sources, le rendu et les règles de production n’ont pas été modifiés par ce harness.

Deux erreurs de fixture sont conservées : un ancien nom d’export dans le premier test Node et une assertion imposant la rangée0 pendant toute l’arrivée d’Hermione. Le premier passage complet 16/16 a ensuite été archivé séparément après le message de root annonçant la dernière condition de soutien dans engineRpg. Le run a été répété intégralement : ses empreintes observées sont identiques à celles de ce passage intermédiaire, ce dernier incluait donc déjà le correctif. Les avertissements de cache Fontconfig n’affectent que les étiquettes des montages techniques ; les captures brutes sont conservées.

Les fixtures fixent PV, jauges et mode automatique pour isoler l’action. Ce contrôle GameCanvas sur le serveur de développement ne vérifie pas la distribution HTTP d’un build final, les dépendances distantes ni les imports construits dynamiquement. Il ne certifie aucune fidélité image par image aux œuvres. Les certificats globaux1:1 restent faux.
